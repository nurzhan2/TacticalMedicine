# W10 — полный аудит после первой игры (20.10)

## Коротко для владельца
- **Почему «хватаю, а не берётся».** Брать можно было только боковой кнопкой GRIP, а подсказка («призрачная перчатка»)
  сгибала и указательный палец, поэтому все жали КУРОК. Радиус захвата был 7 см, подсветки не было. Ещё одна причина:
  предметы в закрытой нагрудной аптечке не брались, пока не дёрнешь язычок.
- **Теперь** брать можно **GRIP или КУРКОМ**. Радиус 9 см, берётся ближайший предмет. Предмет под рукой светится,
  контроллер слегка вибрирует. Отпустил кнопку — предмет выпал.
- **Аптечка** висит на левом бедре и рукам не мешает. Открыть её можно тремя способами: нажать **X**, коснуться её
  рукой (GRIP/КУРОК) или нажать кнопку **АПТЕЧКА** на часах. Тогда перед глазами открывается **лоток**: предметы
  разложены сеткой 5×4, под каждым подпись RU/KZ, нужный сейчас предмет светится. X ещё раз — аптечка уходит обратно на бедро.
- **Рация.** **Зажми Y**: перед глазами появляется панель со строками доклада. Строку выбираешь стиком или лучом +
  КУРОК, отпускаешь Y — доклад отправлен.
- **Подсказки** называют только те кнопки, которые реально работают. Текущий шаг показан на левом запястье и строкой
  внизу поля зрения, со значками кнопок. При первом запуске идёт обучение управлению примерно на 60–90 с: его можно
  пропустить, а повторить — кнопкой «УПРАВЛЕНИЕ» в меню.
- **Выход в меню из любого сценария:** держи **B** 2 секунды. Раньше выйти из сценария было нельзя.
- **Эвакуация.** Раненого тащат так: держишь стропу и тянешь стик назад. Скорость поднята с 0,55 до 1 м/с, до
  вертолёта теперь примерно 50 с вместо 2 минут. Когда вертолёт садится, у его двери пульсирует оранжевый круг.
- Логи твоей игры (`logs/device/play_2010/`) пустые, а шлем не подключён. Поэтому всё проверено тестами, которые
  жмут кнопки виртуального контроллера (Input System XR device), а не через «бота».

## Путь ввода на устройстве (раздел 1 задания)
- OpenXR (Android): профили Meta Quest Touch Plus / Touch Pro + Meta XR feature. Ввод идёт через `OVRInput` (Meta core).
  Вторым источником теперь служит Input System XR controller (`XRControllerHandInput`, объединён в `OVRHandInput`):
  если OVRInput не вернул позу или кнопки, они берутся оттуда. Через этот же источник работают PlayMode-тесты.
- `RuntimeActionBindings.json` (в корне проекта и в `Assets/StreamingAssets/`). Это не наши файлы: их пишет Meta
  OVRPlugin при каждом запуске редактора или batch-сеанса, и оба пустые (`{"InputActionDefinitions": []}`).
  На устройстве используется копия из StreamingAssets, если она попала в APK. Пустой файл означает «биндинги по
  умолчанию», на ввод он не влияет. Оба файла добавлены в `.gitignore`.
- Коллайдеры: после комбинирования мешей аптечки (w9d) коллайдеры предметов **не** удалялись (это проверено тестом
  `Device_X_OpensTray_EveryItemGrabbable_ReturnsToItsCell`: все 20 предметов лотка берутся настоящим вводом).
  Брать не давала закрытая нагрудная аптечка: её предметы были скрыты, пока не дёрнешь язычок. Аптечки на груди больше нет.

## Проход по сценариям и урокам (как игрок)
Проверено чтением шагов `Training.cs` / директоров и прогонами `W10InputDeviceTests`, `DemoFlowTests`, `W4ModesTests`, `ScenarioBotTests`.
- **Обучение управлению** (поворот → GRIP → отпустить → КУРОК → X → CAT в лоток → X → Y → часы → итог): каждый шаг
  называет кнопку. В конце рассказано про волок стиком, фонарь (клик левого стика) и выход по B.
- **ДЕМО и полный TCCC**: дым → бег → жгут → волок → перчатки → … → доклад Y → погрузка. Неясных мест было три: «тащи»
  без стика, дверь вертолёта не видна, «возьми маркер» без «пиши курком». Все три исправлены (баги 6, 7, 21).
- **Уроки жгут / пах / грудь / волок / самопомощь-жгут**: шаги «возьми из аптечки» везде говорят X. Перекат теперь говорит GRIP.
- **Бой и экзамен** (без медицинских подсказок, так задумано): строка управления X · Y · GRIP/КУРОК · B. Во время волока —
  «держи хват, стик назад». После посадки — круг у двери. На итоге — «луч + КУРОК».
- **Самопомощь**: укрытие → X → CAT → вороток → маркер → Y доклад → одеяло → ждать. Каждый шаг с кнопкой. Брифинг
  исправлен (баг 19).

## Не исправлено / на проверку на шлеме
- Голосовые подсказки (`tools/radio_lines.tsv` → wav) местами старые: «стропа на спине бронежилета», «до блиндажа».
  Чтобы их исправить, нужен перегон TTS. Текст на экране правильный.
- В самопомощи остались два радио-интерфейса: нажатие на плечевую рацию и Y-панель. Оба работают. В подсказках только Y.
- В уроке «самопомощь-жгут» строка шага идёт по боевому потоку, а не по шагам урока. Содержание то же.
- Обучающий ящик и карточка ставятся на фиксированное расстояние (0,45 / 0,85 м) без проверки стены: рядом со стеной
  карточка может войти в стену. Меню стоит в открытом месте, на практике это не проявлялось.
- Тексты V1 (траншея) в `ThreatModel`/`CareProtocol` («окоп», «бруствер») в V2 не используются.
- Известные нестабильные тесты (точность бота при тампонаде паха, `BattleSoakTest` — один кадр > 64 КБ, порядок
  `SceneStreamingTests`) описаны в PROGRESS (w9c/w9d). Результат полного прогона w10 — ниже.
