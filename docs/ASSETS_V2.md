## Usage notes for the scene stages
- Every model has `<slug>.prefab` next to the FBX: URP Lit materials from `<slug>.materials.json`, LOD0..2 (LODGroup from `_LODn` names), MeshCollider + tag/layer `Cover` for ruins/cover/vehicles, BoxCollider for props, CapsuleCollider for soldiers, none for aircraft; static flags for scenery.
- Re-run the Unity side with `Field Medic/Assets/Setup Imported Models` (or `-executeMethod FieldMedic.EditorTools.LicensedModelSetup.SetupAll`).
- Visual check: `Field Medic/Assets/Render Gallery` -> `python tools/gallery_sheet.py` -> docs/screens/v2_w1_gallery_*.jpg.
- `_Licensed` is git-ignored: on a fresh clone run `python tools/bk_batch.py tools/bk_batch_w1.txt` (needs %USERPROFILE%\.bk_api_key) before opening scenes that use these prefabs.
- brick_block_wall / scans: some photoscans are one-sided (face toward +Z in the prefab); see the ~back shots in docs/screens/v2_w1_gallery_*.jpg before placing.
