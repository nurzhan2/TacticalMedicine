# Stage S3 — Treatment with the hands (the heart of the game)

Read CLAUDE.md, docs/GDD.md (§5 Interactions spec — implement it faithfully), docs/RESEARCH.md (§3, §4), docs/PROGRESS.md. Time budget ~120 min. Everything must work with `IHandInput` (controllers, hand tracking, desktop simulator, scripted bots).

## Tasks (in priority order — commit after each)
1. **IFAK**: Erlan's IFAK pouch on his plate carrier and the player's own pouch on the player's belt/chest (body-locked to the camera rig at waist height) containing: CAT tourniquet ×2, hemostatic gauze, Israeli bandage, vented chest seal ×2, NPA + lube, decompression needle 14G 3.25", trauma shears, nitrile gloves (grab & "pull on" over hands → hand material becomes purple nitrile), marker, thermal blanket, casualty card. Each item is a `Grabbable` with a realistic simple mesh (Blender procedural script or Unity primitives combined; CAT must be recognisable: black band, red tip/windlass, clip).
2. **Tourniquet state machine** `Runtime/Treatment/TourniquetCAT.cs` exactly as GDD §5: band loop around limb (slide over foot/hand or route around), position along the limb (validated zones from `CasualtyRig` bone segments; joint = invalid), strap pull (slack metric), windlass twist (angle accumulated from wrist roll while gripping the rod; half-turn counting; bleeding residual decreases per half-turn; distal pulse disappears at full occlusion; pain spikes + scream + casualty grabs player's arm), lock in clip, secure strap, mark time with the marker. Feed results into `CareProtocol` (extend Medical: partial occlusion levels, `TourniquetState` with slack/turns/locked/timeMarked, venous congestion when under-tightened = bleeding increases — real-world fact). EditMode tests for the state machine logic (pure C# part).
3. **Limb handling**: grab ankle/calf/knee/wrist → two-bone IK follows the hand with weight and joint limits; pain from velocity & proximity to wound; scream thresholds; the leg can be lifted and held (needed to route the TQ). Release → limb falls back with physics-ish easing.
4. **Drag**: grab the plate-carrier drag handle (and optional drag strap) → casualty root slides on the ground following the hand with friction & mass (lag), head bobbing controlled, body orientation follows pull direction; works in a small room via "pull-to-crawl" (if the player's real movement is blocked, a thumbstick/back-step moves the rig while the hand holds the handle). Into-trench descent: when dragged over an edge, feet first, slight drop animation. TQ may slip when dragged roughly (S7).
5. **Log roll** (two-hand: shoulder + hip) → side position; recovery position snap when roughly correct; back becomes inspectable (hidden wounds, exit wound).
6. **Blood sweep**: open hand moving over body regions slowly discovers hidden wounds (glove gets bloody, haptic, wound becomes `discovered`).
7. **Direct pressure & packing**: palm press on wound (pressure value), gauze roll fed into the wound by repeated finger push strokes (gauze length consumed, visible gauze in wound), 3-min hold timer (Training option ×10 speed), Israeli bandage wrap (N wraps around limb, twist pressure bar, clip). Shears cut along clothing to expose wounds (required before skin-level TQ / packing in TFC).
8. **Chest seal / burp / needle / NPA / recovery position / pulse check / blanket / casualty card / marker on forehead** per GDD §5. Pulse check with haptics at casualty HR (strength ∝ perfusion; absent distal pulse after correct TQ).
9. **Bots**: `Runtime/Scenarios/Bots/MedicBot.cs` drives `ScriptedHandInput` to perform the correct procedure (and deliberately wrong variants) so PlayMode tests can verify: TQ high&tight stops arterial bleed and casualty survives; TQ on knee fails; drag moves casualty ≥3 m; packing+hold+bandage controls groin bleed; chest seal + needle prevents tension death.
10. Screenshots of each step (`docs/screens/s3_*.png`), iterate on visuals.

## Done criteria
All listed interactions usable in the desktop simulator and by bots; tests green; screenshots; pushed; `logs/s3-treatment.done` with summary.
