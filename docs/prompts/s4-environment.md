# Stage S4 — Night trench, combat atmosphere, threats, comfort

Read CLAUDE.md, docs/GDD.md (§7, §8), docs/RESEARCH.md (§1 sounds/visuals), docs/PROGRESS.md. Time budget ~90 min. Visual target: a believable night front-line trench, moody, readable, performant on Quest 3S.

## Tasks
1. **Trench geometry** (Blender headless script `tools/blender/build_trench.py` → `Assets/Art/Environment/Trench.fbx`, or a Unity editor mesh generator — choose what gives better results fast): zig-zag trench ~16 m, depth 1.6–1.8 m, width ~1 m at bottom, timber revetment boards & posts, sandbag parapet (instanced), firing step, covered dugout corner with log roof, communication-trench branch, drainage puddles, cables, ammo crates, anti-drone net over part of the trench. Terrain beyond the parapet: churned field, craters, burnt tree stumps, wire. Use **Poly Haven CC0** textures via their public API (`https://api.polyhaven.com/assets?t=textures`, `https://api.polyhaven.com/files/<id>`; download 1k JPGs only: mud/soil, wet ground, wood planks, sackcloth/burlap, rusty metal) and one night/dark-sky HDRI 1k (or a procedural night skybox if HDRI too big). Record in ATTRIBUTION.md.
2. **Lighting**: very dark scene, moon directional light low intensity (cool blue), player's **red headlamp** (spot, toggle with a button), drifting **illumination flares** (point light + flare sprite + smoke trail, swinging slowly while falling, 30–40 s), explosion flashes (short-lived point lights, pooled), distant horizon glow, tracers (line renderers). Fog. Baked or mixed lighting for the static trench (bake ambient occlusion in Blender textures or Unity lightmaps if time permits). Keep 1 shadow-casting light max.
3. **VFX**: explosion near (flash, dirt burst, smoke, falling debris on player, shockwave dust in trench), explosion far (flash on horizon + delayed sound by distance/343 m/s), dust falling from the dugout roof, rain option.
4. **Audio director** `Runtime/Audio/CombatAmbience.cs` with AudioMixer (master, ambience, sfx, voice, tinnitus/muffle snapshot): night wind/crickets bed, distant artillery & MLRS, machine-gun bursts, drones by type (FPV whine rising, recon quad hum hovering, Shahed moped far above), scripted near-miss events API for scenarios (`PlayDropGrenade(position)`, `PlayIncomingShell(position)`, `PlaySniperCrack()`), near blasts → tinnitus (high tone) + low-pass muffle 3–5 s, camera shake (comfort-limited). Spatial audio (Meta XR Audio SDK spatializer if simple; otherwise Unity 3D sound with good rolloff).
5. **Threat system** `Runtime/Environment/ThreatSystem.cs`: parapet height plane; exposure when player head above it during "under fire" phases; drone overhead state; red-light vs white-light; risk accumulates → warning cues (bullet whiz, impact on parapet) → hit = run ends with explanation. Debrief data.
6. **Comfort**: `Runtime/Comfort/ProximityPassthrough.cs` (OVRPassthroughLayer overlay opacity driven by min distance of head/hands to the OVRBoundary play-area polygon or MRUK walls; 0.6 m → 0.25 m ramp; editor fallback logs distances), snap turn, optional teleport along trench floor, seated mode offset, height calibration.
7. **Main scene** rebuilt with the trench, Ерлан positioned, IFAK, lighting, ambience; screenshots from several bookmarks (`docs/screens/s4_*.png`: wide trench with flare, close dugout, explosion moment, red headlamp on casualty). **Iterate visuals by looking at the screenshots** until it looks like a real night trench.
8. Performance check: script that reports total triangles, draw calls estimate (renderer/material count), texture memory of Main scene → `docs/PERF.md`; fix if over budget.

## Done criteria
Compiles, tests green, screenshots convincing, perf report within budget (or documented), pushed; `logs/s4-environment.done`.
