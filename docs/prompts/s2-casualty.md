## Tasks
1. **Character pipeline (Blender headless script `tools/blender/prepare_casualty.py`)**: import the SKIN fbx, unpack/extract textures, downscale to ≤2048 (albedo/normal; drop unused maps), retint the uniform toward an olive/khaki multicam look appropriate for ВС РК (texture processing in Python/PIL or Blender compositing — keep face/hands untouched), decimate if > 40k tris, export `Assets/Art/Characters/Erlan/Erlan.fbx` (mesh + skeleton, textures as separate files in `Assets/Art/Characters/Erlan/Textures/`) — **must be < 50 MB**. Also model with Blender Python (procedural, low-poly but credible): plate carrier with a **drag handle loop behind the neck**, IFAK pouch with a CAT tourniquet (red/black, separate object), helmet; export as separate FBX in `Assets/Art/Gear/` to be attached to bones in Unity.
2. **Unity import**: Humanoid rig for Erlan and all animation FBX (copy anims to `Assets/Art/Characters/Erlan/Anims/`, configure clips loop flags via AssetPostprocessor `Assets/Editor/MixamoImport.cs`), Animator controller `Erlan.controller` with states: CrouchIdle, LookAround, HitFall_Explosion, HitFall_Shot, HitFall_Shoulder, KnockedOut, LyingWrithing, LyingMoaning, LyingBreathless, LyingCough, LyingDying, Unconscious, RecoverySide, Carried, SittingDazed. Parameters driven by code.
3. **Casualty runtime** (`Runtime/Casualty`): `CasualtyRig` (bone map, `BodyRegion` capsule colliders per bone → `FieldMedic.Medical.BodyRegion`, two-bone IK for both legs/arms usable by grabs in S3, breathing additive (chest/spine scale/rotation by RR & depth), pain flinch, head/eye look at player when conscious), `CasualtyController` (owns `PatientPhysiology` + `CareProtocol`, ticks them, maps AVPU/loss/pain → animator states, skin pallor/cyanosis/sweat via MaterialPropertyBlock, events → voice), `PainModel` (pain level from wounds, handling velocity near wounds, tourniquet twist).
4. **Blood** (`Runtime/Casualty/Blood`): arterial jet particle system pulsing with heart rate (velocity & rate from residual bleed × perfusion), venous ooze drips, cloth soaking (decal/projector or texture-space mask growing around wound on the uniform — URP Decal Projector is fine on mobile if limited; or a shader mask param), ground pool decals that grow with lost volume, blood on player's gloves when touching wounds. Naturalistic: dark red, wet specular, clotting darker edges. Wound meshes/decals per wound type (fragment hole, ragged thigh wound, chest entry/exit, amputation stump with bone — model stump in Blender script).
5. **Sound library**: script `tools/fetch_sounds.ps1` downloads the **best 2–4 per category** from the manifest (prefer CC0, ratings already sorted) into `Assets/Audio/SFX/<cat>/<id>_<slug>.mp3`; skip >5 MB; write `ATTRIBUTION.md` entries (author, freesound URL https://freesound.org/s/<id>/, license). Listen-check is impossible — pick by name/metadata sanity, drop obviously wrong ones (e.g. "spaceship", "Wilhelm", "fireworks" for explosions unless good).
6. **Voice**: `tools/tts_voice.ps1` uses Windows `System.Speech` (check installed voices; prefer a Russian voice like Irina; if none, use whatever exists and note it) to synthesize the casualty lines from RESEARCH §6 (RU + KZ phrases spoken phonetically) into `Assets/Audio/Voice/<lineId>.wav`; add pitch/rate variations, pain strain (post-process in Python: slight pitch drop, breathiness noise, clipping off). `VoiceBank` ScriptableObject maps lineId → clips (RU/KZ) + vocalisation pools (groan, scream, gasp, cough, breath) from Freesound. Write `docs/VOICE_SCRIPT.md`: every line id, RU text, KZ text, emotion, so the owner can record real voice later and drop files with the same names.
7. **Demo**: in Main scene place Ерлан crouching in the placeholder trench; add an editor/PlayMode demo that runs physiology for an arterial thigh wound: he falls (HitFall_Explosion), writhes, bleeds with jets; screenshots `docs/screens/s2_erlan_idle.png`, `s2_erlan_wounded.png` (close-up of wound and blood). Look at them and iterate until it looks credible.
8. Tests: EditMode for PainModel & mapping AVPU→state; PlayMode: casualty bleeds and dies untreated within the expected window; with a tourniquet applied via API survives.
