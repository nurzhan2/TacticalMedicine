## Как установить и что попробовать
1. Режим разработчика на шлеме → USB → **Meta Quest Developer Hub**: перетащить APK. Или adb:
   `"C:\Program Files\Meta Quest Developer Hub\resources\bin\adb.exe" install -r C:\Users\user\Desktop\FieldMedicVR.apk`
2. На шлеме: Библиотека → Неизвестные источники → «Бауыр — Field Medic VR». Встаньте в центр свободной зоны 2×2 м.
3. На доске: **2 СЦЕНАРИИ → 1 «Сброс» → ПУСК**.
   - Дрон сбрасывает ВОГ. Пригнитесь, наложите жгут Ерлана высоко на бедро, крутите вороток до остановки фонтана, заведите его в клипсу и запишите время.
   - Утащите Ерлана в блиндаж за стропу. Там перчатки, осмотр ладонью (осколок в предплечье), одеяло, 4× PTT на рации.
   - Затем появится разбор.
4. Дальше попробуйте «Снайпер» и «КАБ».

## Честно: что не готово / известные проблемы
- На устройстве не проверено. Нужно посмотреть fps в OVR Metrics Tool, масштаб и читаемость текста, удобство хвата.
- Голоса — заглушки TTS, казахские реплики фонетические. Нужна запись носителем (`docs/VOICE_SCRIPT.md`, `tools/radio_lines.tsv`).
- Перчатки процедурные (без текстуры ткани). На шлеме нужно проверить посадку руки относительно контроллера.
- В двух бот-тестах есть подстраховка через протокол, если скриптовая рука промахивается: наклейка на спину (S2) и тампонада ягодицы (S5). В прогоне S6 сработала только одна подстраховка: S5, бот не взял гемостатик. Игрок делает это руками.
- В APK есть разрешения INTERNET и BLUETOOTH (стандарт Unity/Meta, без диалогов).
