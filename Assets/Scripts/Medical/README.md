# Medical core

Движко-независимая модель раненого и правила TCCC/MARCH. Ни одного `using UnityEngine`: код тестируется без редактора и шлема.

| Файл | Что делает |
|---|---|
| `Wound.cs` | Типы ран (артерия, ампутация, узловая, вена, капилляр, грудь), регионы тела, способы остановки кровотечения и остаточный кровоток для каждого |
| `PatientPhysiology.cs` | Кровопотеря по классам ATLS → ЧСС, АД, ЧДД, SpO₂, AVPU, пульс на запястье/шее; гипотермия и коагулопатия; открытый → напряжённый пневмоторакс; западение языка; таймеры жгутов; причина смерти |
| `CareProtocol.cs` | Проверка действий бойца: жгут на суставе/ниже раны/на узловой зоне/на венозном кровотечении, порядок MARCH, «под огнём — только жгут», перчатки, время жгута. Лог действий, штрафы, оценка 0–100 |

Тесты: `Assets/Tests/EditMode` (Window → General → Test Runner → EditMode).

Контрольные цифры (без помощи): артерия бедра — смерть ~5 мин, пах — ~6 мин; загерметизированная рана груди без декомпрессии — напряжённый пневмоторакс через 2 мин, смерть ~6 мин.

⚠️ Цифры подобраны для обучения, не для клинического применения. Все медицинские правила — в `CareProtocol.cs`, перед показом бойцам их должен проверить военный медик.
