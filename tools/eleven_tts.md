# Настоящие голоса из ElevenLabs — инструкция

Скрипт `tools/eleven_tts.py` одной командой заменяет «роботный» голос оператора по рации и инструктора
на голоса из ElevenLabs. Код игры менять не нужно: файлы ложатся в `Assets/Resources/Radio/<id>_ru.wav` и
`<id>_kz.wav` под теми же именами, что сейчас.

## 1. Ключ API (один раз)
1. Зайди на https://elevenlabs.io → войди в аккаунт.
2. Слева внизу нажми на свой профиль → **API Keys** (или открой https://elevenlabs.io/app/settings/api-keys).
3. **Create API Key** → дай имя (например `FieldMedicVR`). Права: достаточно **Text to Speech** и **Voices (read)**.
4. Скопируй ключ (он показывается один раз).
5. Открой PowerShell и выполни (подставь свой ключ):
   ```
   setx ELEVENLABS_API_KEY "sk_твой_ключ"
   ```
6. **Закрой и открой PowerShell заново** — переменная видна только в новых окнах.

Ключ хранится только в переменной окружения Windows. Скрипт его не печатает и никуда не записывает —
никогда не вставляй ключ в файлы проекта (они уходят в git).

## 2. Выбор голосов
В ElevenLabs: **Voices → Voice Library** (библиотека) → фильтр Language: Russian.
- **Оператор (`radio`)**: мужской, спокойный, низкий, «военная рация». Поиск: `military`, `radio`, `narrator deep`,
  `calm male russian`. Должен звучать уверенно и сухо — в игре на него ещё накладывается фильтр рации.
- **Инструктор (`instructor`)**: спокойный, чёткий, дружелюбный, без эмоций. Поиск: `calm`, `instructor`,
  `teacher`, `clear male/female russian`.

Прослушай несколько, нажми **Add to my voices**. Потом в **My Voices** у голоса: меню **⋯ → Copy voice ID**.

## 3. Куда вставить id
Открой `tools/eleven_voices.json` и замени заглушки:
```json
{
  "radio": "ID_голоса_оператора",
  "instructor": "ID_голоса_инструктора"
}
```

## 4. Запуск
Из папки проекта `C:\TacticalMedicine`:
```
python tools\eleven_tts.py --dry-run
```
Покажет все реплики и **сколько символов** уйдёт (ElevenLabs списывает по символам). Сейчас это ~5 200 символов
на все 52 реплики × 2 языка.

Сгенерировать всё:
```
python tools\eleven_tts.py
```
Казахский: модель по умолчанию `eleven_multilingual_v2` хорошо говорит по-русски, но казахского языка в её
списке нет. Для казахского лучше `eleven_v3`:
```
python tools\eleven_tts.py --kz-model eleven_v3
```
(или всё на v3: `--model eleven_v3`).

Полезные флаги:
- `--only h_load,evac_board,evac_away` — только эти реплики;
- `--force` — перегенерировать, даже если файл уже есть (иначе готовые пропускаются);
- `--lang ru` — только русский;
- `--stability 0.4` — живее, `0.7` — ровнее (по умолчанию 0.55);
- `--no-post` — только скачать, без обработки.

Что происходит:
1. Скачанный звук → `SourceAssets/Voice/eleven_raw/<id>_<ru|kz>.wav` (48 кГц, моно; mp3 рядом в `mp3/`).
   Эта папка не попадает в git.
2. `tools/radio_post.py --real` обрабатывает: у оператора — полоса рации, щелчки тангенты, шум; у
   инструктора — только лёгкая чистка. Результат → `Assets/Resources/Radio/`.
3. Открой проект/собери APK — новые голоса уже в игре.

Если реплика не понравилась: `python tools\eleven_tts.py --only <id> --force`.
Тексты реплик — в `tools/radio_lines.tsv` (колонки `ru` и `kz`); после правки текста запусти с `--only <id> --force`.
